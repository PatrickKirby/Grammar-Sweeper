SituationTierWhat the HUD saysWhat the app does
A notification or pop-up takes focus for a momentRecoverableNothing, or "Reconnecting" for a secondBrings Word back to the front by itself
You deliberately switch to another app and work in itNeeds you"You switched to another app. Return to Word to continue."Pauses, stops clicking, resumes when Word is in front again
You bring a different Word document to the frontNeeds you"Word is showing Board Paper.docx. This run is for Delivery Plan vB.docx."Pauses before the next click, never clicks while the wrong document is in front, resumes when the right one returns
You close the Grammarly panelNeeds you"Grammarly was closed. Open it in Word to continue."Pauses, re-checks with growing gaps, resumes by itself when the panel returns
Grammarly restarts or reloadsRecoverable"Reconnecting to Grammarly"Re-finds the panel and carries on
You close the document, with a save promptNeeds you"The document was closed. Reopen it to continue."Pauses. Edits since the last periodic save may be lost if you chose Don't Save, so the HUD says where the backup is
You close Word entirelyFatal"Word was closed."Safe stop, shows the summary and the backup path
Word shows a dialog and stops answeringNeeds you"Word is waiting for you. Close its dialog to continue."Pauses, retries, resumes when Word answers
Nothing useful happens for 5 minutes of running timeFatal"No progress for 5 minutes. Stopped to be safe."Safe stop, summary, backup path, Copy diagnostics. Time spent paused for you does not count, and moving to a new page counts as progress
The computer sleeps or the screen locksNeeds you"Paused while the screen was locked."Sleep is blocked while running. A screen lock cannot be blocked, so the run pauses and resumes after unlock

These behaviours are the design. The retry back-off and the periodic save exist in the engine today. The engine's no-progress stop exists too, but at 20 minutes and counting paused time, so it needs changing to 5 minutes of running time. Detecting a deliberate switch, a different document, a closed document and a blocked dialog are new work.

Fatal error. Safe stop. Diagnostics redact document text by default.
